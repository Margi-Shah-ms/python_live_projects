# 🛍️ Retail Customer Satisfaction Analysis

A Python data analysis project to understand **customer satisfaction, store performance, and purchasing behavior** across retail locations.

### 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

### 🔍 Analysis Performed

* Loaded and explored the customer satisfaction dataset
* Converted `Visit_Date` to datetime and extracted Month & Weekday
* Categorized ratings into **Low, Medium, and High**
* Calculated average ratings by store location
* Analyzed the relationship between **Wait_Time_Min** and `Purchase_Amount`
* Found the weekday with the highest total purchases
* Compared customer recommendations across store locations
