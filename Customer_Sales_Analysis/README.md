# 📊 Customer Sales Analysis

A Python data analysis project to explore **customer purchases, sales trends, and product popularity**.

### 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

### 🔍 Analysis Performed

* Loaded and explored the customer sales dataset
* Checked data types and dataset shape
* Converted `Purchase_Date` to datetime
* Calculated average sales and units purchased
* Found highest and lowest purchase amounts
* Analyzed total sales by **Gender, Region, and Product Category**
* Analyzed purchase trends over time
* Created visualizations using Matplotlib and Seaborn
